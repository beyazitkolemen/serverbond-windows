# ServerBond 1.3.18

Cloud durum eşitlemesi başarısız olursa Windows ajanı bekleyen verileri korur ve 15 saniyeden başlayıp en çok 5 dakikaya çıkan aralıklarla yeniden dener. Böylece geçici Cloud hataları veya kalıcı olarak reddedilen bir durum bölümü saniyede bir istek üretmez. Başarılı gönderim yeniden deneme süresini sıfırlar.

Cloud sunucusu durum POST yanıtında artık kullanılmayan tüm parmak izi listesini göndermiyor. Büyük proje envanterlerinde yanıt boyutu sabit kalır.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
