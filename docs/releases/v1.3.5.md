# ServerBond v1.3.5

Windows’ta açık formların Cloud veya başka bir işlemden gelen değişiklikleri ezmesi önlendi. Taslak korunur, çakışma açıklanır ve kullanıcı güncel veriyi alabilir.

- Sunucu, Hizmetler, API, kuyruk/zamanlayıcı ve sürüm tarifi kayıtları ilk okunan değerlerle karşılaştırılır.
- Dağıtım, kullanıcının gördüğü tarif değişmişse başlamaz.
- .env dışarıdan düzenlenmiş, oluşturulmuş veya silinmişse eski ekran kaydı reddedilir. Dosyayı yeniden yükleme seçeneği eklendi.
- Windows başlangıç kaydının eski/yeni ürün adı arasında taşınmasında geri alma ve etkinlik kontrolü düzeltildi.
- İlk snapshot geldiğinde temiz formların eski değerle etkinleşmesi ve yalnızca boşluk içeren Artisan taslağında Vazgeç’in görünmemesi düzeltildi.

## Doğrulama

23 React testi, 5 odaklı Rust entegrasyon testi, TypeScript/Vite, rustfmt/Clippy; Windows CI standart testleri ve EXE/NSIS kurulum kontrolleri. Uzun servis/indirme testleri ve gerçek kullanıcı oturumunda canlı Cloud işlemleri bu sürüm için çalıştırılmadı. Ayrıntılar: `docs/reviews/windows-reliability-v1.3.5.md`.

## Kurulum

Windows x64 EXE, NSIS kurucu ve SHA256SUMS.txt. Yayın imzasızdır; ServerBond tepsi menüsünden Çıkış seçip kurucuyu elle çalıştırın.
