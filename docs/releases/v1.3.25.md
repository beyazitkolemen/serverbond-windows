# ServerBond 1.3.25

Cloud durum eşitlemesi MySQL ve PostgreSQL bağlantı adresi/portu ile adlandırılmış MySQL veritabanı envanterini de kapsar. Bağlantı bilgileri yalnızca yerel adres, port ve kullanıcı adını içerir; parolalar bu rapora eklenmez. Cloud, bu bilgileri şifreli SQL durumundan gösterir. 700 KB'a kadar geçerli envanter desteklenir. Değişmeyen veri yeniden gönderilmez; MySQL erişilemezken eski envanter kaldırılır ve yeniden erişilebilir olduğunda tekrar alınır.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
