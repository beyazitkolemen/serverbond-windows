# ServerBond 1.3.33

Cloud artık sonuç veya ilerleme gelmeyen eski bir komutu belirsiz olarak kapatabiliyor. Böyle bir komutun gecikmiş sonucuna gelen HTTP 409 yanıtını Windows ajanı kalıcı ret olarak ele alır, sonucu sonsuza dek yeniden göndermeyi bırakır ve yeni komutları yoklamaya devam eder. Cloud tarafından kabul edilmeyen bir masaüstü güncellemesinin bekleyen kurulum kaydı temizlenir; kurulum başlatılmaz.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır. Güncelleme elle kurulur.
