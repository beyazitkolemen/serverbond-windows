# F4Box v1.0

Windows x64 için ilk F4Box sürümü. Uygulama sürümü: **1.0.0**.

## İndirme

- **F4Box_1.0.0_x64-setup.exe**: önerilen kurulum paketi; WebView2 gereksinimini yönetir.
- **F4Box_1.0.0_x64.exe**: doğrudan çalıştırılabilir uygulama; WebView2 önceden kurulu olmalıdır. Veriler `%LOCALAPPDATA%\F4Box` altında saklanır.
- **SHA256SUMS.txt**: iki EXE'nin SHA-256 özetleri. İndirdiğiniz dosyayı PowerShell'de `Get-FileHash .\F4Box_1.0.0_x64-setup.exe -Algorithm SHA256` ile doğrulayabilirsiniz.

## Özellikler

- PHP 7.4–8.5 kataloğu ve proje başına PHP sürümü seçimi.
- MySQL, Caddy, Composer ve phpMyAdmin kurulumu ve yönetimi.
- Mevcut Laravel projelerini ekleme, yeni Laravel 12 projesi oluşturma ve proje terminali.
- SQL yedekleri, bileşen onarımı, günlükler ve yapılandırma kurtarma.
- Windows sistem tepsisi ve isteğe bağlı oturum açılışında başlatma.

## Gereksinimler ve sınırlar

Windows x64, WebView2 ve Microsoft Visual C++ x64 çalışma zamanı gerekir. PHP/MySQL/Caddy gibi bileşenler EXE'ye gömülü değildir; ilk kurulumda internet üzerinden indirilir. Kurulum paketi kod imzalı değildir.

F4Box yerel geliştirme içindir. Node.js, Redis, otomatik HTTPS, kuyruk yönetimi ve MySQL sürüm yükseltmesi bu sürümde bulunmaz. Mevcut proje `.env` dosyaları otomatik değiştirilmez.
