# ServerBond 1.3.35

Cloud eski bir komutu belirsiz olarak kapatsa bile Windows ajanında o işlem hâlâ çalışıyor olabilir. Ajan artık çalışan işlem bitmeden yeni Cloud komutunu yoklayıp teslim almaz. Heartbeat, mevcut işlemin ilerlemesini bildirmeye devam eder. Cloud tarafındaki eşlik eden değişiklik, eski ajanların yoklama yaptığı durumda da yeni komutları bekletir.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır. Güncelleme elle kurulur.
