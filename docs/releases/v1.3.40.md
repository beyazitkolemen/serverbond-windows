# ServerBond v1.3.40

Eksik Windows bağımlılıkları uygulama tarafından hazırlanır:

- **Visual C++ x64:** Açılışta ve bileşen kurulumunda eksik çalışma zamanı Microsoft kaynağından indirilir. SHA-256 ve geçerli Microsoft imzası doğrulanır; Windows yönetici izniyle sessiz kurulur. Gerçek DLL denetimi geçmeden hazır sayılmaz. Otomatik yeniden başlatma yapılmaz.
- **Tekrar deneme:** Kurulum başarısız olursa veya yönetici izni verilmezse her açılışta yeni izin penceresi gösterilmez. Ayarlar → Kurulum gereksinimleri → **Otomatik kur** ile tekrar denenebilir. Sonuç yeniden denetlenir.
- **WebView2:** Kurulum paketi güncelleme sırasında da eksik çalışma zamanını tamamlar. Doğrudan çalıştırılan EXE arayüzü açmadan önce eksik/eski WebView2'yi doğrulanmış Microsoft bootstrapper ile hazırlar.
- **Git:** Sistem Git'i önceliklidir. Bulunamazsa doğrulanmış MinGit uygulamanın kendi klasörüne kurulur; klonlama, yayınlama, Composer ve proje derleme işlemleri kullanabilir. Ön kontroller indirme başlatmaz.
- **Node.js:** Mevcut proje kurulum akışı gerektiğinde taşınabilir Node.js kurar. Sistem PATH ayarları değiştirilmez.

İlk indirmeler internet bağlantısı gerektirir. Windows x64 EXE ve NSIS kurulum paketi imzasızdır; kurulum elle yapılır. Çalışan ServerBond'u tepsi menüsündeki **Çıkış** ile kapatıp yeni kurucuyu çalıştırın. `SHA256SUMS.txt` yayımlanan dosyaların özetlerini içerir.

## Doğrulama

- Yerel Windows: TypeScript/Vite derlemesi, Rust biçim ve Clippy kontrolleri geçti. 26 arayüz testi ve 280 Rust testi başarılı; 10 harici ortam testi varsayılan koşumda atlandı.
- Visual C++ kurulum betiği gerçek PowerShell ile, sistem işlevleri taklit edilerek sınandı: yanlış hash, imzasız dosya ve farklı yayıncı yükleyiciye ulaşamadı. Gerçek Microsoft paketinin hash ve imzası ayrıca doğrulandı.
- Gerçek MinGit indirildi, HTTPS Git erişimi ve yarım kurulumun dosyaları korunarak onarılması doğrulandı.
- Gerçek MySQL/PHP/web/yedek/onarım testi ve MySQL parola değiştirme testi ayrı geçici veri klasörlerinde geçti. Güncel kaynaklardan Windows EXE ve NSIS kurulum paketi üretildi.
- Eksik bağımlılıkları olan temiz bir sanal makinede gerçek sistem kurulumu bu oturumda denenmemiştir; mevcut bilgisayarın çalışma zamanları kaldırılmamıştır. Yerel sonuçlar GitHub Actions sonucu değildir.
