# ServerBond 1.3.23

Cloud durum taraması PHP, tünel ve proje envanteri için aynı Windows durum anlık görüntüsünü kullanır. Bu, her periyodik taramada tekrarlanan tam paket, süreç ve proje kontrollerini azaltır; Cloud'a gönderilen bölüm biçimleri ve değişiklik bildirimleri korunur.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
