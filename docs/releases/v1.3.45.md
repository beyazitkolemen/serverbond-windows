# ServerBond v1.3.45

Cloud bağlantısında tamamlanmış komutların kesinti sırasında gereksiz beklemesi azaltıldı.

- Bağlantı iş parçacığını uyandırma isteği ayrı atomik bayrakta korunur. Blocking HTTP işlemlerinin kullandığı park/unpark mekanizması bu isteği tüketemez.
- Komut tamamlandıysa HTTPS üzerinden kalıcı sonucu iletme, sonraki soket bağlantı denemesinden önce yapılır. Komut journal kaydı ve yeniden deneme davranışı korunur.
- Gerçek geciktirilmiş HTTP yanıtı sırasında uyandırma, sonuç/soket sıralaması ve hata sonrası tekrar için Rust regresyonları eklendi.
- Gerçek Cloud/Reverb/Windows kabulünde Reverb tamamen kapalı üç ardışık komut ayrı SQL ve DOM kimlikleriyle izlenir.

Bu sürüm mevcut imzasız yayın yöntemiyle oluşturulur; elle kurulum gerekir. Mevcut kurulu uygulama ve kullanıcı verileri değiştirilmedi. Canlı özel cihaz ve OAuth kabulü ayrıca doğrulanmalıdır.

Doğrulama: 302 Rust ve 43 arayüz testi, Clippy ve format kontrolleri başarılı. Güncellenmiş Cloud 269 test / 2434 assertion geçti. Gerçek yerel 10 komutta ekranda görünme medyanı 802 ms, maksimum 894 ms; Reverb kapalı üç komut 4,48 / 2,87 / 2,88 saniyede tamamlandı.

Son pakette 9 gerçek izole kurulum/yükseltme/kaldırma senaryosu geçti; mevcut üretim kurulumu değişmedi.
