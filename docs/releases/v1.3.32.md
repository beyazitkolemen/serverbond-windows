# ServerBond 1.3.32

Otomatik dağıtımda tarifin dalı boş bırakıldığında Git çekme artık yerel dalın upstream ayarını kullanmaz. Webhook'a bağlanan GitHub deposunun doğrulanmış uzak adı ve izlenen dal açıkça kullanılır. Böylece upstream başka bir depoya işaret etse de yanlış kaynaktan kod çekilmez. Elle başlatılan dağıtımların Git davranışı değişmez.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır. Güncelleme elle kurulur.
