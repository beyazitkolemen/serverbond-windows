# ServerBond v1.2.0

Proje ve hizmet yönetimi API üzerinden kullanılabilir; sadeleşen masaüstü arayüzüne API merkezi eklendi.

## Yenilikler

- Sol menüde API: bağlantı adresi, port, erişim jetonu, 95 HTTP işlemi, arama/filtreleme ve indirilebilir OpenAPI belgesi.
- Projeler, servisler, PHP sürümleri, veritabanları, yedekler, ortam dosyaları, kuyruk/zamanlayıcılar, GitHub dağıtımları, ayarlar ve masaüstü işlemleri için kimlik doğrulamalı yerel API. API varsayılan olarak kapalıdır ve yalnızca loopback üzerinde dinler.
- Cloudflared ilk açılışta eksikse otomatik indirilir ve SHA-256 doğrulanır. Mevcut sağlam kurulum korunur; tünel açmak için ayrıca bağlantı jetonu gerekir.
- Satır düzeninde hizmetler, kısa bilgilendirmeler, proje/hizmet araması, açık/koyu tema ve Ctrl+K ile hızlı gezinme. Sunucu başlat/durdur terimleri uygulama genelinde tutarlı hale getirildi.
- Windows 10/Server uyumluluk hazırlığı: WebView2 bootstrapper, minimum WebView2 109, uyumlu CSS/JavaScript hedefi ve kurulumda işletim sistemi kontrolü.

## Düzeltmeler

- Windows'ta Herd gibi başka PHP kurulumlarıyla OPcache paylaşımından kaynaklanan PHP başlatma hatası giderildi. Önbellek kimliği ServerBond kurulumuna ve PHP sürümüne göre ayrılır; OPcache açık kalabilir.
- API testlerinde Windows'un serbest bırakılan portu yeniden seçmesinden doğan aralıklı çakışma giderildi.
- Gerçek ayar testi güncel davranışı doğrular: aynı ayarlar kaydedilebilir, çalışan sunucunun çalışma zamanı ayarları değiştirilemez.
- Release akışı gerçek servis testlerini zorunlu çalıştırır; EXE, kurulum paketi ve SHA-256 özetleri tamamlanmadan yayını açmaz.

## Kurulum ve sınırlar

`ServerBond_1.2.0_x64-setup.exe` önerilen kurulum paketidir. `ServerBond_1.2.0_x64.exe` doğrudan çalıştırılabilir; `SHA256SUMS.txt` her iki dosyanın özetini içerir.

Önce tepsi menüsünden **Çıkış** seçin, sonra yeni kurulum paketini çalıştırın. Projeler, veritabanları ve `.env` dosyaları korunur. Açık proje terminallerini yeniden açın.

Bu sürümün EXE dosyaları kod imzalı değildir. Güncelleme imza anahtarı tanımlı olmadığından `latest.json` ve `.sig` yoktur; kurulum elle yapılır. Windows 7/8.1 ve Server 2012 R2 desteklenmez. Windows 10/Server 2019 üzerinde temiz kurulum, yerel WebView2 etkileşimleri ve UAC/otomatik güncelleme kurulumu bu doğrulamaya dahil değildir.

OPcache paylaşım davranışı: [PHP resmi belgesi](https://www.php.net/manual/en/opcache.configuration.php#ini.opcache.cache-id).
