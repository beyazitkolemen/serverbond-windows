# ServerBond 1.3.20

Cloud çok sayıda SQL durum bölümünü yeniden istediğinde Windows ajanı kalan bölümler bitene kadar sonraki heartbeat'lerde parmak izi listesini göndermeye devam eder. Sonraki yanıtta eksik bölüm kalmadığında seyrek, dakikalık uzlaştırmaya döner. Bu, büyük cihaz envanterlerinin Cloud veritabanı sıfırlandıktan sonra gereksiz yere yavaş toparlanmasını önler.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
