# ServerBond 1.3.29

Cloud üzerinden onaylanan masaüstü güncellemesinin hazırlık kaydı artık diske yazılır. Windows uygulaması Cloud sonucu kabul edildikten sonra, kurulum başlamadan önce kapanırsa yeniden açıldığında aynı sonucu Cloud'a tekrar doğrulatır ve onaylanan sürümün kurulumunu sürdürür. Cloud sonucu reddederse kurulum başlatılmaz; yeni sürüm zaten kurulmuşsa eski kayıt temizlenir.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır. Güncelleme elle kurulur.
