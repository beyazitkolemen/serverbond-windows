# ServerBond v1.3.7

- Cloud Laravel kurulumunda ön kontrol, Composer ve kayıt aşamaları canlı bildirilir.
- PHP, Composer ve çalışma klasörü ön kontrolü eksik gereksinimlerle kurulumu engeller. Git ve web portu ayrıca raporlanır.
- Reverb kesintisinde HTTPS üzerinden komut teslimi ve durum raporu devam eder.
- Proje sağlığı: yerel HTTP yanıtı, PHP/MySQL süreçleri, kuyruk ve zamanlayıcı durumu. MySQL süreç bilgisi uygulamanın veritabanı erişimi anlamına gelmez.
- Cloud şablonlarıyla kurulu PHP sürümü, MySQL veritabanı, kuyruk, zamanlayıcı ve dağıtım tercihleri uygulanır. Genel PHP seçimi ve .env dosyası korunur; işçiler otomatik başlamaz.

İmzasız EXE ve NSIS paketidir; kurulumdan önce ServerBond'u tepsiden kapatıp yeni kurucuyu elle çalıştırın. SHA256SUMS.txt yayın dosyalarını doğrular.
