# ServerBond v1.3.6

- Cloud üzerinden mevcut klasör ekleme artık Windows proje çalışma alanını kullanır; yeni Laravel projesi için üst klasör girmek gerekmez.
- Özelleştirilmiş proje klasörü ayarları kullanılır. Var olan hedef dosyaları korunur; geçersiz göreli yollar reddedilir.
- Eksik klasör, geçersiz Laravel kökü, PHP/Composer kurulumu ve uyumsuz işlem parametreleri için açıklayıcı hata mesajları eklenmiştir.
- Kaybolan soket bildirimleri, Cloud heartbeat yanıtındaki bekleyen komut işaretiyle telafi edilir. Sonuç tekrar iletilirken işlem yeniden çalıştırılmaz.

Bu yayın imzasızdır. Windows uygulamasını kapatıp kurulum paketini elle çalıştırın. Cloud eşleştirmesi korunur. Cloud paneli de güncel olmalıdır.

Doğrulama: kısa Cloud sözleşme ve Rust regresyon testleri, Windows CI üzerinde DPAPI/teslim günlüğü testleri ve EXE/NSIS derlemesi. Canlı cihazdaki listeleme akışı doğrulanmıştır; gerçek Composer indirmeli proje kurulumu bu yayında uzun test olarak çalıştırılmamıştır.
