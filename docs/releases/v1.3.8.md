# ServerBond v1.3.8

- Cloud, masaüstü ve yerel API aynı proje kurulum akışını kullanır: GitHub, HTTPS Git, yeni Laravel veya mevcut klasör.
- Kurulumda projeye özel PHP sürümü seçilir; istenirse eksik PHP, Composer ve Node.js katalogdan indirilir ve doğrulanır. Genel PHP seçimi değişmez.
- Klasör erişimi, hedef çakışması, disk ve bileşenler ön kontrolden geçer. Depo erişimi ve uygulama gereksinimleri kaynak alındıktan sonra kontrol edilir.
- Yeni kaynak önce geçici klasörde hazırlanır. Bağımlılık ve derleme hatalarında yarım proje kaydı oluşturulmaz; mevcut klasörler silinmez. Mevcut `.env` için otomatik düzenleme ve isimden türetilen veritabanı oluşturma yoktur.
- Aynı kurulum kimliğinin tekrarı ikinci proje oluşturmaz. Tamamlanmamış kurulumlar otomatik tekrar çalıştırılmaz; kullanıcı dosyaları kontrol ederek yeni istek başlatır.
- İsteğe bağlı `npm ci` ve `npm run build` kurulumda ve yayın tarifinde kullanılabilir. Yayın sırasında frontend derlemesi migration ve işçi yeniden başlatmadan önce çalışır.
- Cloud yayın ayarları ve geçmişi ayrı **Yayınlar** sayfasındadır. Yeni kurulum akışı Windows 1.3.8 gerektirir; eski cihazların mevcut ekleme ekranı korunur.

Bu sürüm kurulum temelini getirir. Yayınlar hâlâ mevcut proje klasöründe çalışır; sürüm klasörleri, otomatik geri alma, Cloudflare hesap/DNS yönetimi, GitHub otomatik yayın, Windows Service ve zamanlanmış yedekleme bu sürümde yoktur. Yeni kurulum internet yayını açmaz; uygulamaya ait ortam/veritabanı ayarları ayrıca tamamlanır.

İmzasız EXE ve NSIS paketidir. Kurulumdan önce ServerBond'u tepsiden kapatıp yeni kurucuyu elle çalıştırın. `SHA256SUMS.txt` yayın dosyalarını doğrular.
