# ServerBond 1.3.15

Rust testleri Nextest ile test dosyaları arasında da paralel çalışır. Yerel komut `npm run test:rust:parallel` sekiz eşzamanlı test sınırı kullanır; Windows ve Linux CI aynı koşucuyu kullanır. Gerçek paket indiren, servis başlatan ve canlı Cloud bağlantısı isteyen `ignored` testler önceki gibi ayrı çalıştırılır.

Sıcak yerel Windows ölçümünde 240 test Nextest ile yaklaşık 13,5 saniyede, önceki `cargo test --workspace --locked` ile yaklaşık 17,7 saniyede tamamlandı. Makine yükü ve önbellek sonucu etkiler.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
