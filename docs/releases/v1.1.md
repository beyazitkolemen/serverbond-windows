# F4Box v1.1

Windows x64 için ikinci F4Box sürümü. Uygulama sürümü: **1.1.0**.

## İndirme

- **F4Box_1.1.0_x64-setup.exe**: önerilen kurulum paketi; WebView2 gereksinimini yönetir.
- **F4Box_1.1.0_x64.exe**: doğrudan çalıştırılabilir uygulama; WebView2 önceden kurulu olmalıdır. Veriler `%LOCALAPPDATA%\F4Box` altında saklanır.
- **SHA256SUMS.txt**: iki EXE'nin SHA-256 özetleri. İndirdiğiniz dosyayı PowerShell'de `Get-FileHash .\F4Box_1.1.0_x64-setup.exe -Algorithm SHA256` ile doğrulayabilirsiniz.

Paketler Windows CI işinden üretilir. GitHub Sürümü yayımlandıktan sonra `v1.1` etiketindeki dosyaları kullanın.

## v1.0'a göre düzeltmeler

- Büyük paket indirmeleri (özellikle MySQL) artık 60 saniyelik toplam istek zaman aşımıyla kesilmez. Bağlantı 30 saniye, tüm indirme en fazla 30 dakika ile sınırlıdır.
- İndirme kullanıcı aracısı `F4Box/0.1` yerine geçerli paket sürümünü gönderir.
- Laravel 12 için PHP 8.2 denetimi `8.10` gibi çift haneli yan sürümleri 8.1 sanmaz; Rust ve arayüz aynı seri karşılaştırmasını kullanır.
- Proje ekleme penceresi, Ayarlar'daki adres kalıbını gösterir (`{name}.dev.localhost` gibi). Artık her zaman `.localhost` varsaymaz.
- Tauri geliştirme sunucusu `127.0.0.1:1420` adresine bağlanır; Windows'ta `localhost` IPv6 çözümlemesi Vite ile kopmaz.
- Zaman aşımına uğrayan veya 8 MB çıktı sınırını aşan alt süreçler bırakılmaz; hemen sonlandırılır.
- `com0` ve `lpt0` proje adları Windows ayrılmış adları olarak reddedilir.
- Arayüz sürüm etiketi `package.json` ile aynı kaynaktan gelir.
- Windows CI Rust araç zincirini kurar, NSIS kurulum paketini üretir ve `F4Box_1.1.0_x64*.exe` ile `SHA256SUMS.txt` yükler.
- Cloud Agent ortamı: `.cursor/environment.json`, `scripts/ai/install.sh`, `npm run test:ai` ve Linux `AI checks` işi. `rust-toolchain.toml` artık Linux asistanların da `stable` kullanmasına izin verir.
- Cursor skill ve kurallar: `.cursor/skills/`, `.cursor/rules/` (her zaman `main`).
- GitHub Releases üzerinden otomatik güncelleme: `tauri-plugin-updater`, Ayarlar → Güncellemeler, tepsi denetimi ve `Release` işi. `latest.json` herkese açık depodan okunur; paket minisign ile doğrulanır. Ayrıntı: [docs/updates.md](../updates.md).
- Proje başına kuyruk işçileri (`queue:work`, birden fazla süreç, `--max-jobs`/`--max-time`) ve Laravel zamanlayıcı (`schedule:work` / crontab karşılığı). Ortamla otomatik başlatma, kayıt sırasında yeni işçileri açma, başlat/durdur/yeniden başlat, `schedule:list --next`, başarısız işler (`queue:failed`/`retry`/`flush`) ve işçi/zamanlayıcı günlükleri.
- Proje kartında PHP, zamanlayıcı ve kuyruk günlüklerini sekmeli görüntüleyici: arama, satır numarası, hata/uyarı vurgusu, kopyalama ve otomatik yenileme.
- Cloudflare tüneli: sabit `cloudflared` paketinin SHA-256 doğrulamalı kurulumu, DPAPI ile şifrelenen bağlayıcı jetonu, Ayarlar → Tünel bölümünden başlat/durdur, ortamla otomatik başlatma ve `cloudflared` günlüğü.
- Node.js LTS kurulumu: sabit paket resmî `SHASUMS256.txt` özetiyle doğrulanır, Ayarlar → Sistem bölümünden kurulur/onarılır ve yalnızca proje terminallerinin PATH'ine `node`, `npm`, `npx` ekler.
- Yerel e-posta yakalama: sabit `mailpit` paketinin SHA-256 doğrulamalı kurulumu, Ayarlar → E-posta bölümünden SMTP/arayüz portu ve saklama sınırı, başlat/durdur, ortamla otomatik başlatma, tepsiden gelen kutusu ve isteğe bağlı olarak PHP `mail()` çağrılarının yakalayıcıya yönlendirilmesi.
- İsteğe bağlı PostgreSQL 17: sabit EDB Windows x64 arşivi SHA-256 ile doğrulanır, Ayarlar → PostgreSQL bölümünden kurulur, port 15432, otomatik başlatma ortamı düşürmez, parola DPAPI, `.env` yazılmaz.
- GitHub’dan proje ekleme: Ayarlar → GitHub’da bir kez kişisel erişim jetonu; Proje ekle → GitHub ile `owner/repo` klonu. Jeton DPAPI; `.env` yazılmaz.
- Proje detayı Ortam sekmesi: kök `.env` düzenleme; yalnızca Kaydet yazar (256 KB, UTF-8).
- Windows izinleri: uygulama açılırken tek bir onay penceresi; güvenlik duvarı, klasör erişimi, Defender istisnası ve sonraki kurulumlar için `F4Box Permissions` zamanlanmış görevi. Reddedilirse bir daha kendiliğinden sorulmaz. Uygulamanın kendisi her açılışta yükseltilmez.
- Yerel HTTPS (Laragon Auto SSL karşılığı): Caddy `tls internal`, isteğe bağlı HTTPS portu (varsayılan 8443), HTTP→HTTPS yönlendirme, Windows kullanıcı Root deposuna sertifika ekleme/kaldırma.
- Proje eklerken/oluştururken MySQL açıksa otomatik veritabanı; proje kartından `.sql` geri yükleme; `projects` çalışma alanında (eski `www` ile birlikte) bir ve iki seviye Laravel kökü taraması.
- Tüm F4Box tercihleri Ayarlar’dan yönetilir: varsayılan PHP sürümü, MySQL root parolası (göster/kopyala/değiştir), çalışma alanı ve yedek klasörü ortam çalışırken kaydedilebilir.

## Değişmeyen sınırlar

Windows x64, WebView2 ve Microsoft Visual C++ x64 çalışma zamanı gerekir. PHP/MySQL/Caddy EXE'ye gömülü değildir. Kurulum paketi kod imzalı değildir. Redis ve MySQL sürüm yükseltmesi bu sürümde yoktur. PostgreSQL isteğe bağlıdır; MySQL varsayılan kalır. Yerel HTTPS Caddy dahili CA kullanır; genel bir sertifika otoritesine bağlanmaz. Node.js isteğe bağlı bir araçtır; sistem PATH'ine yazılmaz ve birden fazla Node sürümü arasında geçiş sunmaz. Yakalanan e-postalar gerçek alıcıya iletilmez; Mailpit dışa giden gerçek bir SMTP aktarıcısı değildir. Cloudflare tünelinin genel adres ve yönlendirme yapılandırması Cloudflare panelinde yapılır; F4Box yalnızca bağlayıcıyı çalıştırır.
