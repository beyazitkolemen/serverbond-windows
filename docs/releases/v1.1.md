# ServerBond v1.1.0

Windows x64 için ikinci ServerBond sürümü. Uygulama sürümü: **1.1.0**.

## İndirme

- **ServerBond_1.1.0_x64-setup.exe**: önerilen kurulum paketi; WebView2 gereksinimini yönetir.
- **ServerBond_1.1.0_x64.exe**: doğrudan çalıştırılabilir uygulama; WebView2 önceden kurulu olmalıdır. Veriler `%LOCALAPPDATA%\ServerBond` altında saklanır.
- **SHA256SUMS.txt**: iki EXE'nin SHA-256 özetleri. İndirdiğiniz dosyayı PowerShell'de `Get-FileHash .\ServerBond_1.1.0_x64-setup.exe -Algorithm SHA256` ile doğrulayabilirsiniz.

Paketler Windows x64 üzerinde yerel olarak derlenmiştir; `v1.1.0` etiketindeki dosyaları kullanın. GitHub Actions hesap ödeme/limit engeli nedeniyle çalışmadı. Depoda güncelleme imza anahtarı tanımlı olmadığı için bu yayın `latest.json` ve `.sig` içermez; kurulum EXE'sini elle çalıştırın. Eski F4Box veri klasörü varsa kullanılmaya devam edilir.

## v1.0'a göre düzeltmeler

- Daha sade açık/koyu arayüz; hizmetler grid yerine her biri tek satır olacak şekilde listelenir.
- Genel bakıştaki açıklamalar kaldırıldı; program genelindeki bilgilendirmeler kısaltıldı. İşlem uyarıları ve hata ayrıntıları korunur.
- Windows yerel Git deposundan proje eklerken klasör adı doğru çıkarılır.
- Testler Redis için boş port seçer; normal test çalışması Windows izinlerini değiştirmez veya yönetici onayı istemez.
- EXE dosyalarının SHA-256 özetleri doğru biçimde üretilir.

- Büyük paket indirmeleri (özellikle MySQL) artık 60 saniyelik toplam istek zaman aşımıyla kesilmez. Bağlantı 30 saniye, tüm indirme en fazla 30 dakika ile sınırlıdır.
- İndirme kullanıcı aracısı `ServerBond/0.1` yerine geçerli paket sürümünü gönderir.
- Laravel 12 için PHP 8.2 denetimi `8.10` gibi çift haneli yan sürümleri 8.1 sanmaz; Rust ve arayüz aynı seri karşılaştırmasını kullanır.
- Proje ekleme penceresi, Ayarlar'daki adres kalıbını gösterir (`{name}.dev.localhost` gibi). Artık her zaman `.localhost` varsaymaz.
- Tauri geliştirme sunucusu `127.0.0.1:1420` adresine bağlanır; Windows'ta `localhost` IPv6 çözümlemesi Vite ile kopmaz.
- Zaman aşımına uğrayan veya 8 MB çıktı sınırını aşan alt süreçler bırakılmaz; hemen sonlandırılır.
- `com0` ve `lpt0` proje adları Windows ayrılmış adları olarak reddedilir.
- Arayüz sürüm etiketi `package.json` ile aynı kaynaktan gelir.
- Windows CI Rust araç zincirini kurar, NSIS kurulum paketini üretir ve `ServerBond_1.1.0_x64*.exe` ile `SHA256SUMS.txt` yükler.
- Cloud Agent ortamı: `.cursor/environment.json`, `scripts/ai/install.sh`, `npm run test:ai` ve Linux `AI checks` işi. `rust-toolchain.toml` artık Linux asistanların da `stable` kullanmasına izin verir.
- Cursor skill ve kurallar: `.cursor/skills/`, `.cursor/rules/` (her zaman `main`).
- GitHub Releases üzerinden otomatik güncelleme altyapısı: `tauri-plugin-updater`, Ayarlar → Güncellemeler, tepsi denetimi ve `Release` işi. İmzalı yayınlarda `latest.json` herkese açık depodan okunur; paket minisign ile doğrulanır. Bu yayında elle kurulum gerekir. Ayrıntı: [docs/updates.md](../updates.md).
- Proje başına kuyruk işçileri (`queue:work`, birden fazla süreç, `--max-jobs`/`--max-time`) ve Laravel zamanlayıcı (`schedule:work` / crontab karşılığı). Ortamla otomatik başlatma, kayıt sırasında yeni işçileri açma, başlat/durdur/yeniden başlat, `schedule:list --next`, başarısız işler (`queue:failed`/`retry`/`flush`) ve işçi/zamanlayıcı günlükleri.
- Proje kartında PHP, zamanlayıcı ve kuyruk günlüklerini sekmeli görüntüleyici: arama, satır numarası, hata/uyarı vurgusu, kopyalama ve otomatik yenileme.
- Cloudflare tüneli: sabit `cloudflared` paketinin SHA-256 doğrulamalı kurulumu, DPAPI ile şifrelenen bağlayıcı jetonu, Hizmetler → Tünel bölümünden başlat/durdur, ortamla otomatik başlatma ve `cloudflared` günlüğü.
- Node.js LTS kurulumu: sabit paket resmî `SHASUMS256.txt` özetiyle doğrulanır, Ayarlar → Sistem bölümünden kurulur/onarılır ve yalnızca proje terminallerinin PATH'ine `node`, `npm`, `npx` ekler.
- Yerel e-posta yakalama: sabit `mailpit` paketinin SHA-256 doğrulamalı kurulumu, Hizmetler → E-posta bölümünden SMTP/arayüz portu ve saklama sınırı, başlat/durdur, ortamla otomatik başlatma, tepsiden gelen kutusu ve isteğe bağlı olarak PHP `mail()` çağrılarının yakalayıcıya yönlendirilmesi.
- İsteğe bağlı PostgreSQL 17: sabit EDB Windows x64 arşivi SHA-256 ile doğrulanır, Hizmetler → PostgreSQL bölümünden kurulur, port 15432, otomatik başlatma ortamı düşürmez, parola DPAPI, `.env` yazılmaz.
- GitHub’dan proje ekleme: Hizmetler → GitHub’da bir kez kişisel erişim jetonu; Proje ekle → GitHub ile `owner/repo` klonu. Jeton DPAPI; `.env` yazılmaz.
- Hizmetler sol kenar çubuğunda: phpMyAdmin, e-posta, PostgreSQL, Redis, GitHub ve tünel Ayarlar’dan ayrıldı. Port ve jeton her hizmetin içindeki Ayarlar düğmesindedir.
- Kenar çubuğu üç grup: Çalışma alanı, Ortam, alta sabitlenen Yönetim. Seçili satırda vurgu çubuğu.
- Hizmet onarımı: eksik kurulumda Kur yerine Onar; onay penceresi; veri/jeton/`.env` korunur; `repairable` durumu kartta görünür.
- Hizmet sayfalarında ortak üst denetim şeridi: durum, Kur / Başlat / Durdur / Aç.
- İsteğe bağlı Redis 8.10.2: Windows x64 MSYS2 paketi SHA-256 ile doğrulanır, Hizmetler → Redis’ten kurulur, port 16379, otomatik başlatma ortamı düşürmez, `.env` yazılmaz.
- Proje detayı Ortam sekmesi: kök `.env` düzenleme; yalnızca Kaydet yazar (256 KB, UTF-8).
- Windows izinleri: uygulama açılırken tek bir onay penceresi; güvenlik duvarı, klasör erişimi, Defender istisnası ve sonraki kurulumlar için `ServerBond Permissions` zamanlanmış görevi. Reddedilirse bir daha kendiliğinden sorulmaz. Uygulamanın kendisi her açılışta yükseltilmez.
- Yerel HTTPS (Laragon Auto SSL karşılığı): Caddy `tls internal`, isteğe bağlı HTTPS portu (varsayılan 8443), HTTP→HTTPS yönlendirme, Windows kullanıcı Root deposuna sertifika ekleme/kaldırma.
- Proje eklerken/oluştururken MySQL açıksa otomatik veritabanı; proje kartından `.sql` geri yükleme; `projects` çalışma alanında (eski `www` ile birlikte) bir ve iki seviye Laravel kökü taraması.
- Tüm ServerBond tercihleri Ayarlar’dan yönetilir: varsayılan PHP sürümü, MySQL root parolası (göster/kopyala/değiştir), çalışma alanı ve yedek klasörü ortam çalışırken kaydedilebilir.
- Yerel yönetim API'si: `127.0.0.1:18800/api/v1` altında Bearer jetonlu HTTP uçları; arayüzün ve CLI'nın tüm işleri (hizmetler, projeler, sürüm, kuyruk/zamanlayıcı, `.env`, ayarlar) betikten yönetilebilir. Ayarlar → API'den açılır; jeton bir kez gösterilir, diskte yalnızca özeti kalır. CLI: `serverbond api serve|token|forget|status|routes`. Bkz. `docs/api.md`.
- Kuyruk işçisi denetimi: azami iş/süre dolunca temiz kapanan işçi çökme sayılmaz ve otomatik yeniden başlatılır; yeniden başlatma ve sürüm sırasında `queue:restart` gönderilip süren işin bitmesi beklenir.
- Dayanıklılık düzeltmeleri: Windows izin betiğinin BOM'lu JSON çıktısı okunur (tekrarlayan UAC istemi kalktı), tipografik kesme işaretli klasör yolları PowerShell'e güvenli aktarılır, Redis çalışıyorken "port dolu" hatası verilmez ve `noeviction` politikası kullanılır, PostgreSQL parola değişimi kilitlenmeye yol açmaz, GitHub jetonu yalnızca github.com'a gönderilir, `.env.example` proje dışına çıkamaz, sürüm çıktısı adım başına sınırlanır, geçmiş yazma hatası dağıtımı başarısız saymaz.
- Arayüz: ayar formları anlık görüntü yenilemesinde yazılan değeri kaybetmez, sayı alanları boşaltılabilir, sürüm tarifi metin alanı Enter'ı yutmaz, pencereler Escape sonrası tutarlı kalır, sayfa çökmesi yalnızca o sayfayı etkiler. Sistem/açık/koyu tema; `StatusBadge`, `NumberField`, `SegmentedControl`, `EmptyState` paylaşılan bileşenleri.

## Değişmeyen sınırlar

Windows x64, WebView2 ve Microsoft Visual C++ x64 çalışma zamanı gerekir. PHP/MySQL/Caddy EXE'ye gömülü değildir. Kurulum paketi kod imzalı değildir. MySQL sürüm yükseltmesi bu sürümde yoktur. PostgreSQL ve Redis isteğe bağlıdır; MySQL varsayılan kalır. Yerel HTTPS Caddy dahili CA kullanır; genel bir sertifika otoritesine bağlanmaz. Node.js isteğe bağlı bir araçtır; sistem PATH'ine yazılmaz ve birden fazla Node sürümü arasında geçiş sunmaz. Yakalanan e-postalar gerçek alıcıya iletilmez; Mailpit dışa giden gerçek bir SMTP aktarıcısı değildir. Cloudflare tünelinin genel adres ve yönlendirme yapılandırması Cloudflare panelinde yapılır; ServerBond yalnızca bağlayıcıyı çalıştırır.
