# F4Box v1.1

Windows x64 için ikinci F4Box sürümü. Uygulama sürümü: **1.1.0**.

## İndirme

- **F4Box_1.1.0_x64-setup.exe**: önerilen kurulum paketi; WebView2 gereksinimini yönetir.
- **F4Box_1.1.0_x64.exe**: doğrudan çalıştırılabilir uygulama; WebView2 önceden kurulu olmalıdır. Veriler `%LOCALAPPDATA%\F4Box` altında saklanır.
- **SHA256SUMS.txt**: iki EXE'nin SHA-256 özetleri. İndirdiğiniz dosyayı PowerShell'de `Get-FileHash .\F4Box_1.1.0_x64-setup.exe -Algorithm SHA256` ile doğrulayabilirsiniz.

Paketler Windows CI işinden üretilir. GitHub Sürümü yayımlandıktan sonra `v1.1` etiketindeki dosyaları kullanın.

## v1.0'a göre düzeltmeler

- Büyük paket indirmeleri (özellikle MySQL) artık 60 saniyelik toplam istek zaman aşımıyla kesilmez. Bağlantı 30 saniye, tüm indirme en fazla 30 dakika ile sınırlıdır.
- İndirme kullanıcı aracısı `F4Box/0.1` yerine geçerli paket sürümünü gönderir.
- Laravel 12 için PHP 8.2 denetimi `8.10` gibi çift haneli yan sürümleri 8.1 sanmaz; Rust ve arayüz aynı seri karşılaştırmasını kullanır.
- Proje ekleme penceresi, Ayarlar'daki adres kalıbını gösterir (`{name}.dev.localhost` gibi). Artık her zaman `.localhost` varsaymaz.
- Tauri geliştirme sunucusu `127.0.0.1:1420` adresine bağlanır; Windows'ta `localhost` IPv6 çözümlemesi Vite ile kopmaz.
- Zaman aşımına uğrayan veya 8 MB çıktı sınırını aşan alt süreçler bırakılmaz; hemen sonlandırılır.
- `com0` ve `lpt0` proje adları Windows ayrılmış adları olarak reddedilir.
- Arayüz sürüm etiketi `package.json` ile aynı kaynaktan gelir.
- Windows CI Rust araç zincirini kurar, NSIS kurulum paketini üretir ve `F4Box_1.1.0_x64*.exe` ile `SHA256SUMS.txt` yükler.
- Cloud Agent ortamı: `.cursor/environment.json`, `scripts/ai/install.sh`, `npm run test:ai` ve Linux `AI checks` işi. `rust-toolchain.toml` artık Linux asistanların da `stable` kullanmasına izin verir.

## Değişmeyen sınırlar

Windows x64, WebView2 ve Microsoft Visual C++ x64 çalışma zamanı gerekir. PHP/MySQL/Caddy EXE'ye gömülü değildir. Kurulum paketi kod imzalı değildir. Node.js, Redis, otomatik HTTPS, kuyruk yönetimi ve MySQL sürüm yükseltmesi bu sürümde yoktur.
