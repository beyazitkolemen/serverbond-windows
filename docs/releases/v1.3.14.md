# ServerBond 1.3.14

Windows CI'de süreç çıktı sınırını doğrulayan testin ortak koşucu yüküne bağlı 10 saniye varsayımı kaldırıldı. Test, 8 MB sınırının komutu 20 saniyelik zaman aşımından ve komutun 30 saniyelik son bekleyişinden önce durdurduğunu doğrulamaya devam eder.

1.3.13'teki Vitest hızlandırması, Cloud SQL durum koruması ve API sınırlarına uygun durum gönderimi bu sürüme dahildir. Cloud sürümü önce güncellenmelidir.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
