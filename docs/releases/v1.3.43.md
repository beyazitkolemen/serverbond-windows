# ServerBond v1.3.43

PostgreSQL veri koruması, Cloud yeniden eşleştirme ve arayüzdeki eşzamanlı okuma sorunları düzeltildi.

- **PostgreSQL:** Önceden oluşturulmuş veri klasörü kayıpsa boş veritabanı hazırlanmaz. Dosya bilgisi veya DPAPI parolası okunamıyorsa sunucu başlatılmadan hata bildirilir; mevcut veri/parola korunur. Kümenin oluşturulması SQL bağlantı hazır olma durumundan ayrı kaydedilir.
- **Cloud:** Eski cihaz eşleştirmesinin geç gelen durum, socket ve işlem sonucu yanıtları yeni eşleştirmeyi iptal edemez veya yeniden deneme süresini değiştiremez. İşlem tesliminde cihaz kimliği yeniden denetlenir.
- **Sürüm ekranı:** Dağıtım sonrası geçmiş için yeni IPC isteği açılır; önceki okuma yeni çıktıyı ezmez. Seçilen geçmiş çıktısının dal, commit ve süre bilgileri aynı kayıttan gösterilir. Yükleme ve hata durumları ayrılır.
- **GitHub:** Dal listesi yüklenirken adres ile eklemeye geçiş, ekranı yüklemede kilitlemez.
- **Klavye:** Tema ve diğer seçenek gruplarında tek Tab durağı, yön tuşlarıyla seçim/odak, Home/End ve devre dışı durum davranışı eklendi.
- **Doğrulama araçları:** MCP ve tam kurucu testi `CARGO_TARGET_DIR` seçimine uyar; ayrı D: derlemesi kullanılırken eski EXE sınanmaz. README sürüm bilgisi güncellendi.

## Doğrulama

- 43 arayüz testi ve 296 workspace Rust testi geçti; harici ortam gerektiren 12 Rust testi varsayılan koşumda atlandı. Doc-test hedefinde test bulunmuyor.
- Gerçek PostgreSQL parola değiştirme, SQL kaydı, kayıp veri klasörünü reddetme, klasörü geri getirip aynı Türkçe kaydı okuma akışı ayrı geçici veri klasöründe başarılı.
- Resmi MCP SDK ile 106 aracın gerçek yerel API bağlantısı, okuma/yazma ve hata davranışı başarılı.
- TypeScript/Vite, rustfmt ve workspace Clippy (`-D warnings`) kontrolleri geçti. Üretim npm bağımlılıklarında `npm audit --omit=dev` bilinen açık bildirmedi.
- Playwright ile `http://127.0.0.1:1420` üzerinde 1440×950, 900×650 ve 390×844 ekranlarda gezinme, geçmiş çıktısı seçimi ve tema/klavye akışları başarılı; boş ekran, framework hata katmanı veya konsol hatası görülmedi. Browser eklentisi bu oturumda bulunmadığından mevcut Chrome ve Playwright kullanıldı.
- NSIS kurulum yolu için 3, WebView2 bölümü için 11 kontrollü senaryo başarılı.
- Güncel EXE ile tam kurucu yaşam döngüsünün 9 senaryosu geçti; üretim kurulumunun dosya/kayıtları korunarak gerçek izole kurulum, güncelleme ve kaldırma doğrulandı (`HostUnchanged=true`).
- Gerçek v1.3.43 masaüstü EXE ayrı D: test veri klasöründe açıldı; WebView erişilebilirlik ağacında sürüm ve genel bakış doğrulandı. Masaüstü HTTP API'sinden açık/koyu tema kaydı, dosyaya kalıcılık ve düzenli çıkış başarılı; mevcut kurulu EXE'nin SHA-256 özeti değişmedi. Test klasöründe host izin değişiklikleri önceden reddedildi ve üretim servisleri başlatılmadı.

Cloud yarış testleri yerel HTTP yanıtları ve gerçek Windows DPAPI kullanır; canlı Cloud/OAuth/Cloudflare kabulü değildir. Tarayıcı kontrolleri örnek verili salt okunur önizlemedir; gerçek masaüstü IPC ve servis kabulü değildir.

Windows UI otomasyonunda monitör yakalama (`0x80070057`) ve imleç erişimi (`0x80070005`) başarısız oldu. Bu nedenle gerçek masaüstü tıklama/klavye ve ekran görüntüsü kontrolü tamamlandı sayılmaz; tema kaydı yerel masaüstü API'siyle doğrulandı.

Eksik Visual C++/WebView2 bulunan temiz Windows'ta gerçek sistem kurulumu ve yönetici izni, Windows 10/Server ve MSI geçişi ayrıca doğrulanmalıdır. PostgreSQL veri klasörü ile oluşturulma kaydı iki ayrı dosya işlemidir; bu sürüm tam bir çökme atomikliği veya yeni yedekleme/rollback sistemi sunmaz.

Windows x64 EXE ve NSIS paketi imzasızdır; elle kurulum gerekir. Kurucudan önce ServerBond'u tepsi menüsündeki **Çıkış** ile kapatın. `SHA256SUMS.txt` yayımlanan dosyaların özetlerini içerir. Yerel doğrulama GitHub Actions sonucu değildir.
