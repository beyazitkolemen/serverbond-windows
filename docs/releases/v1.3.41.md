# ServerBond v1.3.41

Windows bağımlılıklarının otomatik kurulumu, veri koruma ve ayarların doğru güncellenmesi güçlendirildi.

- **Windows gereksinimleri:** Bozulmuş Visual C++ ve WebView2 yükleyicileri geçerli eski kurulum kaydına rağmen yeniden doğrulanır ve onarılır. MinGit denetimi HTTPS, sertifika ve çalışma zamanı dosyalarını da kapsar. Eski WebView2'nin güncellenmesi ve sessiz kurulum hata akışları düzeltildi; taşınabilir EXE'nin hazırlık işlemi sınırlı süre ve çıktı boyutuyla çalışır.
- **Redis:** Normal durdurmada son yazılar diske kaydedilir. Kaydetme başarısız olursa servis açık tutulur ve hata bildirilir; kuyruk/oturum verilerinin sessizce kaybolması önlenir. Başarısız çıkış denemesinden sonra uygulamanın ayar/onarma işlemleri ve API erişimi kullanılabilir kalır.
- **Git:** Klonlama mevcut hedef klasörü reddeder; başarısız işlem kullanıcının mevcut dosyalarını silemez. Güncelleme, sistemdeki rebase/autostash ayarlarını devre dışı bırakarak yerel değişiklikleri korur.
- **Arayüz:** Geç kalan API ve masaüstü ayar sorgularının yeni kaydedilen durumu geri alması düzeltildi. Kaydetme sonrasındaki sorgu eski bekleyen IPC isteğine bağlanmaz.

Visual C++ x64, WebView2 ve gerektiğinde taşınabilir Git/Node.js uygulama akışında hazırlanır. İlk indirme internet, Visual C++ kurulumu Windows yönetici izni gerektirir. Sistem PATH ayarları değiştirilmez.

Windows x64 EXE ve NSIS paketi imzasızdır; elle kurulum gerekir. ServerBond'u tepsi menüsündeki **Çıkış** ile kapatıp yeni kurucuyu çalıştırın. `SHA256SUMS.txt` dosyası yayımlanan paketlerin özetlerini içerir.
