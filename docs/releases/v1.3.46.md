# ServerBond v1.3.46

Cloud bağlantısında tekrar eden TCP/TLS kurulum maliyeti azaltıldı.

- Pair, revoke, heartbeat, poll, socket bootstrap ve durum gönderimi Manager başına ortak HTTP bağlantı havuzunu kullanır. Anahtarlar her istek için ayrı uygulanır; timeout ve yönlendirme güvenliği korunur.
- Gerçek 20 istek regresyonunda TCP bağlantısı20→1; aynı bağlantıda anahtar değişimi doğrulanır.
- Başarılı işlem sonrasında arayüz eski poll'a katılmak yerine yeni snapshot ister. Normal okuma birleştirme davranışı korunur; geç eski sonuç yeni durumu ezmez.

Mevcut imzasız yayın yöntemi kullanılır; elle kurulum gerekir. Kurulu uygulama veya kullanıcı verileri değiştirilmedi. Canlı özel cihaz/OAuth ve temiz Windows kabulü ayrı kapsamdır.
