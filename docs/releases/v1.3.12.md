# ServerBond 1.3.12

Windows yayınında gerçek servis testleri değişen dosya ve paketlere göre seçilir. MySQL değişikliği artık ilgisiz PHP sürüm matrisi, Cloudflared ve diğer indirme testlerini başlatmaz.

Birden fazla gerçek ortam testi gerektiğinde doğrulanmış paket arşivleri aynı yayın işi içinde paylaşılır; her test ayrı geçici veritabanı ve servis dizininde çalışır. Test seçimi otomatik testlerle doğrulanır.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
