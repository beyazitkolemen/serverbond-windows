# ServerBond 1.3.28

Cloud tarafından şema veya boyut nedeniyle reddedilen bir komut çıktısı artık aynı içerikle sonsuza kadar yeniden gönderilmez. Windows ajanı işlemi tekrar çalıştırmadan yerel günlüğe `uncertain` kaydeder ve Cloud'a sonucu belirsiz olarak bildirir. Belirsiz bildirimi geçici olarak başarısız olursa sonraki bağlantıda güvenle yeniden dener.

Masaüstü güncellemesinin hazırlık sonucu Cloud tarafından reddedilirse kurulum başlatılmaz. Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
