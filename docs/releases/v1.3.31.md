# ServerBond 1.3.31

Cloud üzerinden gelen otomatik dağıtım komutu artık GitHub deposunu ve izlenen dalı Windows üzerinde, Git çekme veya diğer dağıtım adımları başlamadan doğrular. Projenin kayıtlı dağıtım dalı, Git uzak deposu ya da Git çekme ayarı webhook bağıyla eşleşmiyorsa komut başarısız olur; farklı bir dal veya depo yanlışlıkla dağıtılmaz. Elle başlatılan dağıtımların mevcut davranışı korunur.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır. Güncelleme elle kurulur.
