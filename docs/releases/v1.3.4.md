# ServerBond v1.3.4

Cloud panelinde cihaz ekleyin, bağlantı kodunu kopyalayın ve Windows’ta Ayarlar → Cloud bölümüne yapıştırıp **Cloud’a bağlan** düğmesine basın. Hesap, cihaz ve soket ayarları otomatik tanımlanır.

- Varsayılan Forge sunucusu için adres, port veya soket anahtarı girilmez. Özel sunucular gelişmiş ayarlarda düzenlenebilir; kayıtlı özel adresler korunur ve gösterilir.
- Kopyalanan koddaki boşluk ve tireler temizlenir. Eksik kodlar gönderilmez; bağlantı sürerken yinelenen gönderimler engellenir.
- Eşleştirme tamamlanınca bağlantı döngüsü hemen uyandırılır. Eski durum sorguları yeni eşleştirmeyi ekranda geri alamaz.
- Geçersiz kod, istek sınırı ve geçici durum okuma hataları ayrı açıklanır. Eşleştirme ile canlı soket bağlantısı ayrı gösterilir.
- Kayıtlı bağlantı sonraki açılışlarda otomatik kurulur; ağ kesintilerinde yeniden denenir.

## Doğrulama

16 React testi, 6 odaklı Rust Cloud testi, TypeScript/Vite derlemesi; Cloud tarafında eşleştirme, kanal yetkileri ve yönlendirme metinlerini kapsayan 18 test / 186 assertion. Windows CI, EXE ve NSIS kurulum kontrollerini çalıştırır. Gerçek Windows cihazıyla canlı eşleştirme bu çalışma kapsamında yapılmadı.

## Kurulum

Windows x64 EXE, NSIS kurucu ve SHA256SUMS.txt. Yayın imzasızdır; ServerBond tepsi menüsünden Çıkış seçip kurucuyu elle çalıştırın.
