# ServerBond v1.3.2

Windows Cloud bağlantısı artık Forge sunucusunu varsayılan olarak kullanır.

- Ayarlar → Cloud ekranında `https://serverbond.on-forge.com` hazır gelir. İlk bağlantıda panelden alınan kod yeterlidir; sonraki açılışlarda bağlantı otomatik kurulur.
- Soket adresi ve anahtarı Cloud’dan alınır. Kayıtlı özel sunucular korunur; varsayılan sunucuya dönme seçeneği vardır.
- Eşleştirilmiş cihaz ile canlı soket bağlantısı ayrılır. Bağlanıyor, bağlı, yeniden deneniyor ve yeniden eşleştirme durumları gösterilir.
- Cihaz, hesap, Cloud sunucusu, soket adresi ve son başarılı iletişim tek ekranda görüntülenir. Düzenlenen adres arka plan yenilemesinde kaybolmaz.
- v1.3.1 kaynaklarında hazırlanan, Cloud üzerinden sürüm denetimi ve açık onaylı imzalı güncelleme desteğini de içerir.

## Kurulum

EXE, Windows x64 NSIS kurulum paketi ve `SHA256SUMS.txt` yayımlanır. İmzasız paket elle kurulur; kurucuyu çalıştırmadan önce tepsi menüsünden Çıkış seçin. İmzalı uzaktan güncelleme desteği bu paketin imzalı olduğu anlamına gelmez.

## Doğrulama

Değişikliğe odaklı Cloud testleri, frontend derlemesi ve Windows checks akışının test/derleme sonuçları yayın için kullanılır. Uzun süren gerçek servis indirme testleri bu değişiklik için çalıştırılmaz. Gerçek Windows cihazının Forge’a eşleştirilmesi ve uzaktan uygulama yükseltme bu yayının otomatik doğrulama kapsamı dışındadır.
