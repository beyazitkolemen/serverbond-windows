# ServerBond 1.3.9

Cloud hesabından gelen kısa ömürlü GitHub App jetonları özel depo klonu ve dağıtım çekiminde kullanılabilir. Jeton diske hesap kimliği olarak yazılmaz.

## Değişiklikler

- `projects.github`, `projects.setup` (GitHub kaynağı) ve `projects.deploy` isteğe bağlı `accessToken` parametresini kabul eder
- GitHub App kurulum jetonları (`ghs_`) doğrulanır
- Mevcut Windows DPAPI hesap jetonu yolu eski sürümler için durur
