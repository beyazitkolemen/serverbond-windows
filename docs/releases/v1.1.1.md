# ServerBond v1.1.1

Kod ve paket yapısı ServerBond adına geçirildi.

- Rust çekirdeği `serverbond-core`, masaüstü uygulaması `serverbond-desktop.exe`, npm paketi `serverbond` oldu.
- Tauri kimliği `com.serverbond.desktop`, tepsi kimliği `serverbond-tray` olarak değişti.
- PHP, Composer, proje terminali ve işçi süreçleri `SERVERBOND_PHP_EXT` kullanır. Test önbelleği `SERVERBOND_TEST_CACHE` ile seçilir.
- Varsayılan PHP e-posta göndereni `serverbond@localhost` oldu.
- Derleme iş akışları, geliştirme yönergeleri, klasörler ve belgeler yeni adlarla güncellendi.
- Eski kurulumların veri yolu, başlangıç kaydı ve okuma takma adları tek bir uyumluluk modülünde korundu. Projeler ve `.env` dosyaları taşınmaz.

## Kurulum

`ServerBond_1.1.1_x64-setup.exe` önerilen Windows x64 kurulum paketidir. `ServerBond_1.1.1_x64.exe` doğrudan çalıştırılabilir; `SHA256SUMS.txt` her iki dosyanın özetlerini içerir.

Önce tepsi menüsünden **Çıkış** seçin. Kurulumdan sonra açık proje terminallerini yeniden açın. WebView2 ve Microsoft Visual C++ x64 çalışma zamanı gerekir.

Bu yayın yerel Windows derlemesidir, EXE'ler kod imzalı değildir. Güncelleme imza anahtarı tanımlı olmadığından `latest.json` ve `.sig` içermez; elle kurulur.

## Doğrulama

- TypeScript/Vite, Rust biçim kontrolü, Clippy ve Windows NSIS derlemesi başarılı.
- `cargo test --workspace --locked`: 127 test başarılı; gerçek paket gerektiren 4 test varsayılan çalışmada atlandı.
- Ayrı çalıştırılan `branding_runtime` testi başarılı: OPcache kapalıyken gerçek PHP CLI/FastCGI, Caddy web isteği, Türkçe yolda PHP uzantıları, proje terminali, Composer ve `.env` korunması doğrulandı.
- Ayrı çalıştırılan `preferences_runtime` testi, PHP 7.4 OPcache doğrulamasında Windows ASLR hatası nedeniyle başarısız oldu (`Opcode handlers are unusable due to ASLR`). OPcache senaryosu bu yayında doğrulanmış sayılmaz.
- Ayrı çalıştırılan `environment` testi PHP başlatılırken `0xfffffffe` çıkış koduyla başarısız oldu; bu testin tam servis/onarım senaryosu bu yayında doğrulanmadı.
- Tüm PHP sürümlerini indiren `php_matrix` testi çalıştırılmadı.
