# ServerBond 1.3.37

Cloud durum eşitlemesinde proje UUID'sinin yalnızca harf büyüklüğü değiştiğinde ajan artık aynı bölümü hem güncelleyip hem silmiyor. Bölüm geçici olarak okunamıyorsa önceki parmak izi korunuyor. Böylece Cloud'da proje ayrıntısının kısa süreli kaybolması önleniyor.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır. Güncelleme elle kurulur.
