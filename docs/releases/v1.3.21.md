# ServerBond 1.3.21

Cloud bağlantısı kaldırılıp başka bir cihaza yeniden eşleştirildiğinde ajan eski cihazın durum parmak izlerini, son tarama zamanını ve geri deneme bekleme süresini temizler. Böylece yeni cihazın proje, servis ve ayar durumu Cloud SQL veritabanına hemen gönderilir. Eşzamanlı eski bir tarama da yeni bağlantının durumunu değiştiremez.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
