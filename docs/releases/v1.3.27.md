# ServerBond 1.3.27

Cloud'a gönderilecek MySQL envanteri boyut sınırını aşarsa Windows ajanı son başarılı envanteri korur ve eşitlemeyi eksik sayar. Böylece Cloud panelindeki önceki veritabanı listesi geçici boyut hatasında silinmez. MySQL envanteri okunamazsa mevcut kaldırma davranışı sürer.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
