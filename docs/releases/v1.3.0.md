# ServerBond v1.3.0

Windows cihazınızı ServerBond Cloud hesabınıza bağlayıp hizmet ve projelerinizi uzaktan yönetebilirsiniz. Masaüstü arayüzü ve ekran görüntüleri güncellendi.

## Yenilikler

- **Ayarlar → Cloud:** tek kullanımlık kodla eşleştirme, bağlantı durumu ve bağlantıyı kaldırma. Özel Laravel Reverb kanalı komutları anlık bildirir; cihaz komutları kimlik doğrulamalı HTTPS üzerinden alır ve sonuçlarını iletir.
- Cloud üzerinden desteklenen hizmet kurulum/onarım işlemleri, proje yönetimi, PHP seçimi, kuyruk ve zamanlayıcılar, veritabanları, günlükler, tünel ve ayarlar. Cihaz kendi desteklediği işlemleri bildirir; değişiklikler ilgili onay ve sürüm kontrollerinden geçer.
- Ortam dosyası ve ayar kaydetmede eşzamanlı değişiklik kontrolü; tamamlanan Cloud komutlarının sonuçları Windows DPAPI ile korunur ve yeniden bağlantıda aynı komut tekrar yürütülmez.
- GitHub cihaz yetkilendirmesi, depo/dal seçimi ve proje aktarımı. API ve MCP bağlantı yönetimi aynı merkezde bulunur.
- Bağlı masaüstü uygulamasında Cloud üzerinden görünüm ve başlangıç/tepsi tercihleri; başsız cihaz bu masaüstü yeteneklerini bildirmez.
- Proje ayrıntıları için sol bölüm menüsü, düzenlenmiş formlar ve günlük akışları. Yeni kurulumların varsayılan veri dizini `C:\ServerBond`, proje dizini `C:\ServerBond\www`; mevcut özel yollar korunur.

## Düzeltmeler

- API rehberinin sorgu parametresi olmayan uç noktalarda açılmasını engelleyen hata giderildi.
- Güncelleme keşfi `serverbond-windows` yayınlarını kullanır.
- Windows süreç temizliği, dosya yazımı ve proje keşfi sağlamlaştırıldı; MySQL SQL içeriği süreç argümanlarına taşınmaz.

## Doğrulama ve görüntüler

TypeScript/Vite derlemesi, Rust biçim kontrolü, çalışma alanı testleri ve Clippy yerel Windows ortamında geçti. Release akışı ayrıca gerçek Windows paket/servis testlerini çalıştırır. Ayrı Laravel/Reverb test ortamı isteyen Cloud uçtan uca testi bu yayın akışına dahil değildir; yerel WebView2 etkileşimleri ve Cloud üzerinden gerçek masaüstü başlangıç davranışı bu sürüm hazırlığında yeniden doğrulanmadı.

[20 güncel ekran görüntüsü](https://github.com/beyazitkolemen/serverbond-windows/tree/v1.3.0/docs/screenshots), salt okunur tarayıcı önizlemesinden örnek verilerle alındı. Cloud görüntüsü eşleştirilmemiş durumu gösterir.

## Kurulum

`ServerBond_1.3.0_x64-setup.exe` kurulum paketini indirin. Önce mevcut uygulamanın tepsi menüsünden **Çıkış** seçin, ardından kurucuyu çalıştırın. Projeler, veritabanları ve `.env` dosyaları korunur.

`ServerBond_1.3.0_x64.exe` doğrudan çalıştırılabilir. `SHA256SUMS.txt` iki dosyanın doğrulama özetlerini içerir. İmzasız pakette kurulum elle yapılır; Windows 7/8.1 ve Server 2012 R2 desteklenmez.
