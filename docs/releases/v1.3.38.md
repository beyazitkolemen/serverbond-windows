# ServerBond 1.3.38

Cloud durum eşitlemesi, proje işçi ve zamanlayıcı bilgilerini tek uygulama görüntüsünden hazırlar. Çok projeli kurulumlarda her proje için tüm paket ve süreç durumunu yeniden okumaz. Masaüstü arayüzü boşta daha seyrek durum sorgular; işlem sürerken hızlı güncellemeye devam eder.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır. Güncelleme elle kurulur.
