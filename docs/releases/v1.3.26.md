# ServerBond 1.3.26

Çekirdek Rust testlerinin varsayılan komutu Nextest ile paralel çalışır. Yerel ve CI testlerinde işçi sayısı kullanılabilir mantıksal işlemci sayısına göre en fazla sekizdir; `SERVERBOND_TEST_JOBS` ile değiştirilebilir. Seri karşılaştırma komutu korunmuştur. Linux AI test akışı aynı paralel komutu kullanır.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
