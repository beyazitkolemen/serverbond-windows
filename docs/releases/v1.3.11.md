# ServerBond 1.3.11

Cloud panelindeki adlandırılmış MySQL veritabanı ve kullanıcı işlemleri artık Windows ajanında çalışır.

## Değişiklikler

- Veritabanı envanteri, yeni veritabanı oluşturma ve seçilen veritabanlarına yetkili kullanıcı oluşturma komutları eklendi.
- Salt okunur kullanıcıya yalnızca `SELECT` yetkisi verilir. Veritabanı adındaki alt çizgi MySQL `GRANT` deseninde kaçırılır.
- Veritabanı yetki envanteri MySQL istemcisinin toplu çıktı kaçışlarından etkilenmez.
- Kullanıcı oluşturma sırasında yetki verme başarısız olursa yeni hesap geri alınır. Parola işlem sonucuna, günlüğe ve proje `.env` dosyasına girmez.
- İzole gerçek MySQL yayın testi adlandırılmış veritabanını, kullanıcı yetkisini ve parola gizliliğini sınar.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
