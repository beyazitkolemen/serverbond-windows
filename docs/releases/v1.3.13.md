# ServerBond 1.3.13

Arayüz testleri Vitest iş parçacığı havuzunda çalışır. Windows üzerindeki 24 UI testi yerel ölçümde yaklaşık 27 saniyeden 4 saniyeye indi; test kapsamı değişmedi.

Cloud durum taramasında bir bölüm geçici olarak okunamazsa Windows, Cloud SQL'deki son geçerli kaydı silmez. Tamamlanmamış taramalar heartbeat'te açıkça işaretlenir; Cloud yalnızca tamamlanmış envanterden silme yapar. Cloud sürümü önce güncellenmelidir.

Çok projeli cihazlarda durum gönderimi Cloud API'nin istek başına 40 bölüm, 40 kaldırma ve 768 KB sınırına göre parçalara ayrılır.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
