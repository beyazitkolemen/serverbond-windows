# ServerBond 1.3.19

Komut almak için yapılan Cloud `poll` istekleri artık SQL durum parmak izi listesini taşımıyor. Windows ajanı tam listeyi yalnızca dakikada bir heartbeat ile bildirir; Cloud'da kaybolan kayıtların yeniden eşitlenmesi sürer. Başarısız heartbeat bu süreyi başlatmaz ve bir sonraki denemede liste yeniden gönderilir.

Bu sürüm imzasız Windows EXE ve NSIS kurulum paketiyle yayımlanır; güncelleme elle kurulur.
