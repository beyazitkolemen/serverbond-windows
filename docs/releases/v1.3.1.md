# ServerBond v1.3.1

Cloud panelinden Windows sürümünü denetleme ve onaylı, imzalı güncelleme kurulumunu başlatma desteği.

- Cihaz raporu uygulama sürümünü içerir; Cloud, yeniden bağlantıda gerçekten çalışan sürümü gösterir.
- `desktop.update-check` mevcut ve yeni sürümü, güncelleme uygunluğunu ve kurulum yöntemini bildirir.
- `desktop.update-install` yalnızca açık onay verilmiş, daha yeni ve imzalı sürümü kabul eder. Sunucular/işçiler çalışıyorsa kurulum reddedilir; indirme sonrasında yeniden kontrol edilir.
- İmza doğrulaması Tauri güncelleyicisinde yapılır. Paket hazırlandıktan sonra sonuç Cloud tarafından kabul edilmeden kurulum başlamaz. Geçici teslim hataları yeniden denenir; erişim iptalinde bekleyen kurulum atılır.
- Bağlı masaüstü hostu olmayan cihazlar güncelleme komutlarını bildirmez.

## Doğrulama

Windows çalışma alanı testleri, Cloud komut/onay testleri, HTTP sonuç teslimi ve iptal testleri, Rust biçim kontrolü ve Clippy çalıştırıldı. Testlerde kurulum hostu taklit edilir; gerçek uygulamanın uzaktan yükseltilip yeniden açılması ayrıca doğrulanmalıdır.

## İlk geçiş

v1.3.0 ve önceki Windows sürümlerinde Cloud güncelleme komutu yoktur. Uzaktan güncellemeyi kullanabilmek için destekleyen sürümü bir kez yerelden kurun. Uzaktan kurulum yalnızca cihazın güvenilen açık anahtarıyla doğrulanabilen imzalı yayınlarda kullanılabilir; imzasız paketler elle kurulur.
